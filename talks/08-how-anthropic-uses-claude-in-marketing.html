นักการตลาดที่ไม่เคยเขียนโค้ด ใช้ Claude Code สร้าง Figma plugin สร้างโฆษณาหลายแบบใน 30 วินาที

How Anthropic uses Claude in Marketing

ผู้พูด: Austin Lau (Growth marketer ที่ Anthropic (ตามคำอธิบายคลิป))

เหมาะกับ: คนทำ marketing หรืองานสร้างสรรค์ที่ไม่เขียนโค้ดและมีงานซ้ำๆ ใน Figma หรือเครื่องมืออื่น

Austin Lau ไม่เคยเขียนโค้ดมาก่อน ใช้ Claude Code สร้าง Figma plugin ที่รับ headline หลายแบบครั้งเดียว แล้วสร้างโฆษณาแต่ละแบบเป็น frame แยก ผู้พูดบอกว่างานที่เคยใช้ราว 30 นาทีเหลือราว 30 วินาที และแนะนำให้เริ่มจากงานซ้ำๆ เล็กๆ ที่อธิบายปัญหาให้ชัดได้

A non-coder growth marketer used Claude Code to build a Figma plugin that generates ad variants from one pasted list, cutting about 30 minutes of work to about 30 seconds.

ประเด็นสำคัญ

  1. ผู้พูดบอกว่าไม่เคยเขียนโค้ดเลย ถึงขั้นต้อง Google ว่าเปิด terminal บน Mac อย่างไร และตอน Claude Code เปิดตัวยังไม่เข้าใจว่าใช้ทำอะไร
  2. งานของเขาครอบคลุม paid social และ app store ที่ใช้ visual creative ใน Figma ซึ่งทีมออกแบบเป็นคนสร้าง
  3. ปัญหาคือต้องทำหลายแบบ: copy frame เดิม วาง headline จาก Google Doc สลับไปมา ทำซ้ำ 10 แบบ x 5 aspect ratio เวลาสะสมเร็วมาก
  4. เขาให้ Claude Code สร้าง Figma plugin ที่ให้วาง copy ทั้งหมดครั้งเดียว
  5. เดโม: เลือก frame, เปิด plugin, กด identify template components (ระบุส่วนประกอบเช่น headline, CTA, code block), เลือกอัปเดตแค่ headline, วางรายการ headline, กด generate ad variants ได้แต่ละแบบเป็น frame แยก
  6. ผู้พูดบอกว่างานเดิมประมาณ 30 นาที ตอนนี้ราว 30 วินาที
  7. คำแนะนำสำหรับคนไม่เขียนโค้ด: ดูงานที่ซ้ำหรือน่าจะ automate ได้ เริ่มจากเรื่องเล็กและง่ายมาก
  8. สิ่งที่ต้องมีคืออธิบายปัญหาและสิ่งที่อยากได้ให้ชัดเจนกระชับ ช่องว่างระหว่างอยากให้มี กับสร้างเองได้ เล็กกว่าที่คนคิด

ลำดับขั้นที่ทำในคลิป

  1. เลือก frame ที่เป็น template โฆษณาใน Figma
  2. เปิด Figma plugin ที่สร้างไว้ด้วย Claude Code
  3. กด identify template components ให้ plugin ระบุ headline, CTA และ code block
  4. ติ๊กเลือกเฉพาะส่วนที่จะอัปเดต (ในเดโมคือ headline)
  5. คัดลอกรายการ headline จากเอกสารแล้ววางใน plugin ครั้งเดียว
  6. กด generate ad variants ได้แต่ละแบบเป็น frame แยก

ตัวเลข / ข้อเท็จจริงที่ผู้พูดบอก

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • ความแปรผันที่ต้องทำ: 10 แบบ ข้าม 5 aspect ratio
  • เวลาเดิมประมาณ 30 นาที เหลือประมาณ 30 วินาที (ผู้พูดบอก)

“I've never written a single line”

สิ่งที่นำไปทำต่อ

  • ไล่หางานซ้ำๆ ในกระบวนการของตัวเอง แล้วเลือกชิ้นเล็กสุดมาลองก่อน
  • อธิบายปัญหาให้ Claude Code ด้วยภาษาธรรมดา ไม่ต้องรู้โค้ด
  • ลองสร้างเครื่องมือเฉพาะทาง เช่น plugin สำหรับเครื่องมือที่ใช้อยู่ทุกวัน
  • จับเวลาก่อน-หลัง เพื่อรู้ว่าคุ้มจริงไหม

ข้อควรระวังในสรุปนี้

  • ชื่อและตำแหน่งผู้พูดมาจากคำอธิบายคลิป ไม่ได้ยินแนะนำตัวใน transcript
  • auto-caption สะกด Claude Code เป็น Cloud Code แก้ตามบริบท
  • ตัวเลข 30 นาที เป็น 30 วินาที เป็นข้ออ้างของผู้พูด ไม่มีหลักฐานวัดจริงในคลิป
  • ไม่ได้แสดงว่า Claude Code สร้าง plugin ขึ้นมาอย่างไร (prompt/ขั้นตอนการสร้าง) เดโมแสดงเฉพาะการใช้ plugin ที่เสร็จแล้ว
  • คำอธิบายคลิปมีทั้ง 'building Figma plugins' และ 'automated ad generation workflows' แต่ใน transcript เห็นเฉพาะ Figma plugin
