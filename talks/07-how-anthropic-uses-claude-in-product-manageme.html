How Anthropic uses Claude in Product Management

ผู้พูด: Lisa Crofoot (Product Manager ที่ Anthropic (ตามคำอธิบายคลิป))

เหมาะกับ: Product manager ที่ต้องรอ data science ทุกครั้งที่อยากได้ตัวเลข ไม่ต้องรู้ SQL

Lisa Crofoot เล่าว่า PM ที่ Anthropic ใช้ Claude Code ต่อกับ BigQuery MCP ที่ทีม data science ตั้งไว้ เพื่อถามข้อมูลผลิตภัณฑ์และทำกราฟได้เองโดยไม่ต้องเขียน SQL อีกด้านคือให้ Claude ขยาย test case สำหรับ evals จากตัวอย่างไม่กี่อันเป็นราว 50 อัน เป้าหมายคือให้ PM มีเวลากับกลยุทธ์ การคุยลูกค้า และการตัดสินใจมากขึ้น

PMs use Claude Code with a BigQuery MCP to query product data and chart it without SQL, and to expand a few eval examples into about 50, freeing time for strategy and decisions.

ประเด็นสำคัญ

  1. ผู้พูดบอกว่า PM ตอนนี้ทดสอบไอเดียกับ Claude ก่อนดึงคนอื่นเข้ามา ทำให้ iterate เร็วและทำงานได้อิสระขึ้น
  2. ปัญหาเดิมคือต้อง ping คน data science หรือเขียน SQL พื้นฐานเองบนฐานข้อมูลที่ไม่ค่อยรู้จัก
  3. ทีม data science ตั้ง BigQuery MCP เชื่อมตารางข้อมูลผลิตภัณฑ์ทั้งหมดเข้า Claude Code ผู้ใช้แค่ตีความข้อมูลและผลลัพธ์ ไม่ต้องเขียน SQL
  4. เดโมใช้ข้อมูลสังเคราะห์ที่ Claude สร้าง เรื่องสัดส่วนการใช้ dark mode เทียบ light mode ย้อนหลัง 3 เดือน โดยระบุตารางให้ Claude
  5. Claude เปิดกราฟพร้อมของที่ไม่ได้สั่ง เช่น 7-day rolling average และค่าเฉลี่ยรวม ผู้พูดว่าสวยกว่าที่ทำเอง จากนั้นสั่งแตกกราฟตาม plan type ได้ต่อ
  6. ผู้พูดประเมินว่าถ้าทำเองอาจใช้หลายชั่วโมงหรือมากกว่า
  7. อีกการใช้งานคือสร้าง evals: ให้สถานการณ์ ประสบการณ์ผลิตภัณฑ์ที่ต้องการ กับตัวอย่าง test case สองสามอัน แล้วให้ Claude ขยายเป็นราว 50 อัน
  8. ผู้พูดมองว่าเป็นมากกว่า automation คือทำสิ่งที่เดิมทำเองไม่ได้ เป็นการขยายความสามารถของตัวเอง

ลำดับขั้นที่ทำในคลิป

  1. ทีม data science ตั้ง BigQuery MCP เชื่อมตารางข้อมูลผลิตภัณฑ์เข้ากับ Claude Code
  2. สร้างข้อมูลสังเคราะห์ light/dark mode usage สำหรับเดโม
  3. สั่งใน Claude Code ให้ดูสัดส่วน dark mode ย้อนหลัง 3 เดือน พร้อมระบุตารางที่ใช้
  4. Claude เปิดกราฟ (มี 7-day rolling average และค่าเฉลี่ยรวมเพิ่มเอง)
  5. สั่งแตกกราฟตาม plan type; Claude ขออนุญาตแก้ไฟล์ ผู้พูดอนุญาต แล้วได้กราฟใหม่
  6. สำหรับ evals: ให้สถานการณ์ + ตัวอย่าง test case แล้วให้ Claude ขยายชุด test case

ตัวเลข / ข้อเท็จจริงที่ผู้พูดบอก

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • ข้อมูลเดโม: สัดส่วน dark mode ย้อนหลัง 3 เดือน (ข้อมูลสังเคราะห์)
  • ตัวอย่าง test case: จาก 1-2 อัน ขยายเป็นราว 50 อันสำหรับ evals
  • กราฟที่ Claude เพิ่มเอง: 7-day rolling average และค่าเฉลี่ยรวม

ประโยคเด่น (ต้นฉบับ)

“I can use Claude to test my product ideas before I even get anyone else in the loop.”

ใช้ Claude ทดสอบไอเดียผลิตภัณฑ์ก่อนดึงใครเข้ามาเกี่ยวด้วยซ้ำ

“You just need to be a human interpreter of that data and that result.”

แค่เป็นมนุษย์ที่ตีความข้อมูลและผลลัพธ์นั้นก็พอ

“So, really quickly you go from one or two examples to test to like 50”

จากตัวอย่าง 1-2 อัน กลายเป็นราว 50 อันอย่างรวดเร็ว

สิ่งที่นำไปทำต่อ

  • ให้ทีม data ตั้ง MCP ต่อตารางที่ปลอดภัยให้ PM ใช้ แล้ว PM ถามเป็นภาษาธรรมชาติได้
  • ระบุชื่อตารางให้ชัดเวลาสั่ง และตรวจผลที่ตีความเองเสมอ
  • ให้ Claude ขยายชุด test case ของ evals จากตัวอย่างจริงไม่กี่อัน
  • เอาเวลาที่ประหยัดไปใช้กับกลยุทธ์และการคุยลูกค้า

ข้อควรระวังในสรุปนี้

  • ชื่อและตำแหน่งผู้พูดมาจากคำอธิบายคลิป ไม่ได้ยินแนะนำตัวใน transcript
  • ใน auto-caption คำว่า evals ถูกสะกดเป็น e-bells ซ้ำสองครั้ง แก้เป็น evals ตามบริบท (evaluate AI systems)
  • เดโมใช้ข้อมูลสังเคราะห์ ไม่ใช่ข้อมูลผลิตภัณฑ์จริง
  • ไม่ได้บอกตัวเลขวัดผลเชิงปริมาณ ข้ออ้างเรื่องเร็วขึ้นเป็นความเห็นของผู้พูด
  • คำอธิบายคลิปพูดถึงการสร้าง evals 'ในไม่กี่นาที' ซึ่งผู้พูดไม่ได้ระบุเวลาชัดใน transcript
