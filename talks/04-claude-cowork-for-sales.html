How Anthropic uses Claude ทุกคลิปสรุปรวม

#04 · Claude Cowork · 3:32

AE ใช้ Cowork เตรียมประชุมลูกค้าครั้งแรกและสรุปงานหลังประชุมในไม่กี่นาที

Claude Cowork for sales

ผู้พูด: Brittany (growth account executive ดูแลพอร์ตลูกค้า startup เชิงกลยุทธ์ (ตามที่แนะนำตัวในคลิป))

เหมาะกับ: ทีมขายหรือ account manager ที่ข้อมูลลูกค้ากระจายหลายระบบ และอยากรู้วิธีสร้าง skill จากการคุยกับ Claude

Brittany สร้าง skill ใน Cowork ชื่อ account strategy builder ที่ดึงข้อมูลลูกค้าจาก Salesforce, data warehouse, อีเมล, Slack และเว็บพร้อมกัน แล้วสรุปเป็น account brief ก่อนประชุมครั้งแรก หลังประชุมใช้ skill call transcript processor สร้าง action items, ข้อความ Slack ภายใน และข้อความตามลูกค้า ทั้งหมดรออนุมัติก่อนส่ง

A growth AE builds a Cowork skill that pulls CRM, warehouse, email, Slack and web data into an account brief before a first customer call, and another that turns the call transcript into follow-ups pending her approval.

ประเด็นสำคัญ

  1. ก่อนคุยลูกค้าครั้งแรก ต้องรู้เร็วว่าลูกค้าคือใคร สร้างอะไร ใช้ Claude อย่างไร ใช้จ่ายเท่าไร และมีความเสี่ยงกับแนวโน้มการเติบโตอะไร ข้อมูลพวกนี้มีอยู่แต่กระจายใน Salesforce, data warehouse, call recordings, Slack, email และเว็บ
  2. การสร้าง skill ทำโดยเปิด session ใน Cowork แล้วอธิบายว่าอยากรู้อะไรตอนเดินเข้าประชุม Claude ร่างไฟล์ skill ให้จากบทสนทนานั้น
  3. ไฟล์ skill คือไฟล์ text ที่บอก Claude ว่าจะเข้าหางานอย่างไร: ดูแหล่งข้อมูลไหน สัญญาณ usage แบบไหนสำคัญ และนำเสนอผลอย่างไร
  4. ใน settings เธอต่อ data warehouse, Salesforce, เว็บ, อีเมล และ Slack ไว้แล้ว และเลือกโฟลเดอร์บน desktop ที่ Claude อ่าน แก้ และบันทึกไฟล์ได้
  5. เธอลอง skill กับบัญชีทดสอบ ปรับแก้ และเพราะเป็น plain text จึงเปิดตรวจได้เสมอว่า skill ทำอะไร
  6. ก่อนประชุม พิมพ์ / เลือก skill account strategy builder แล้วใส่ชื่อบัญชี (ตัวอย่าง Acme Corp) Claude รัน data pulls พร้อมกัน ได้แก่ calls 90 วันล่าสุด แนวโน้มรายได้ open opportunities ใน Salesforce ข้อมูลใน email/calendar/Slack และข่าว funding จากเว็บ
  7. Claude สังเคราะห์เป็น strategy doc เก็บในโฟลเดอร์ของบัญชี อ่านเหมือน account brief เต็ม มีข้อมูลการใช้จ่าย stakeholder mapping โมเดล Claude ที่ลูกค้าใช้สร้าง open deals และ risk signals
  8. หลังประชุม กลับมา session เดิมที่ยังมี account context อยู่ พิมพ์ / เลือก call transcript processor Claude ดึง transcript แล้วสร้าง 3 อย่าง: action items ส่วนตัว, ข้อความ Slack ภายในที่มี key takeaways next steps และ action owners, และข้อความตามลูกค้า แต่ละชิ้นรออนุมัติก่อนส่งจริง ผู้พูดบอกว่า flow หลังประชุมที่เคยใช้ 30 นาที เหลือไม่กี่นาที และละเอียดกว่าที่เขียนจากความจำ

ลำดับขั้นที่ทำในคลิป

  1. เปิด session ใน Cowork แล้วอธิบายว่าอยากรู้อะไรก่อนเข้าประชุมลูกค้า ให้ Claude ร่างไฟล์ skill จากบทสนทนา
  2. ตั้งค่า connectors ใน settings: data warehouse, Salesforce, เว็บ, อีเมล, Slack และเลือกโฟลเดอร์บน desktop ที่ Claude อ่าน แก้ บันทึกได้
  3. ทดลอง skill กับบัญชีทดสอบ ปรับแก้ ตรวจไฟล์ plain text ว่า skill ทำอะไร
  4. ก่อนประชุม: เข้า Cowork พิมพ์ / เลือก account strategy builder ใส่ชื่อบัญชี (ตัวอย่าง Acme Corp)
  5. Claude รัน data pulls พร้อมกัน: calls 90 วัน, revenue trends, open opportunities ใน Salesforce, email/calendar/activity/Slack, ข่าว funding จากเว็บ
  6. Claude สังเคราะห์เป็น strategy doc เก็บใน account folder (spend, stakeholder mapping, โมเดลที่ใช้, open deals, risk signals)
  7. หลังประชุม: กลับ session เดิม พิมพ์ / เลือก call transcript processor
  8. Claude ดึง transcript สร้าง action items ส่วนตัว, ข้อความ Slack ภายใน, ข้อความตามลูกค้า แล้วรออนุมัติทีละชิ้นก่อนส่ง

ตัวเลข / ข้อเท็จจริงที่ผู้พูดบอก

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • ดึง calls ย้อนหลัง 90 วันของบัญชี
  • flow หลังประชุมเดิมใช้ประมาณ 30 นาที เหลือ "ไม่กี่นาที" (ผู้พูดประเมินเอง)
  • ผลลัพธ์หลังประชุม 3 ชิ้น: action items ส่วนตัว, Slack ภายใน, ข้อความตามลูกค้า
  • แหล่งข้อมูลที่ต่อ 5 แหล่ง: data warehouse, Salesforce, เว็บ, อีเมล, Slack (รวมถึง calendar/call recordings ที่ดึงตอนรัน)

ประโยคเด่น (ต้นฉบับ)

“Clod drafted a skill file from that conversation, which is basically a text file that tells Clod how to approach the task.”

Claude ร่างไฟล์ skill จากบทสนทนา ซึ่งคือไฟล์ text ที่บอก Claude ว่าจะเข้าหางานอย่างไร (ASR เขียน Clod)

“Instead of spending the meeting just getting oriented, I can show up with real context and make the first impression count.”

แทนที่จะใช้เวลาประชุมปรับตัว เธอไปถึงพร้อม context จริงและสร้างความประทับใจแรกได้

“Now, the whole post-meeting flow that used to take me 30 minutes is done in just a couple of minutes, and it's way more thorough than what I'd write from memory.”

flow หลังประชุมที่เคยใช้ 30 นาที เสร็จในไม่กี่นาที และละเอียดกว่าที่เขียนจากความจำ

สิ่งที่นำไปทำต่อ

  • อธิบายให้ Cowork ฟังว่าอยากรู้อะไรก่อนเข้าประชุม แล้วให้มันร่างไฟล์ skill ให้ ไม่ต้องเขียนเองจากศูนย์
  • ต่อ connectors ที่ข้อมูลลูกค้ากระจายอยู่ แล้วให้ skill ดึงทุกแหล่งพร้อมกัน แทนไล่เปิดทีละระบบ
  • ทดสอบกับบัญชีทดลองและเปิดไฟล์ plain text ตรวจได้ว่า skill ทำอะไร ก่อนใช้กับลูกค้าจริง
  • ใช้ session เดียวต่อเนื่องก่อนและหลังประชุม เพื่อให้ Claude มี account context ติดอยู่ตอนสรุปงานตามหลัง
  • ตั้งให้ทุกข้อความที่ออกไปข้างนอกรอการอนุมัติของคนก่อนส่งเสมอ

ข้อควรระวังในสรุปนี้

  • Transcript เป็น YouTube auto-caption สะกด Claude เป็น "Clod" / "Cloud" และ Cowork เป็น "Co-work" ในหลายจุด ชื่อ skill "account strategy builder" กับ "call transcript processor" ตามที่ฟังได้ ยังไม่ยืนยันการสะกดทางการ
  • ต้นคลิปมีบรรทัด "Hey Mark. Hi, I'm Brittany." เป็นการทักทายสั้นๆ ไม่ชัดว่า Mark คือใคร (อาจเป็นคนทักในซีรีส์เดียวกัน) ไม่ได้นำมาใช้
  • นามสกุลของ Brittany ไม่ได้ยินในเสียงพูด และไม่มีชื่อบริษัทในเสียง คำอธิบายคลิปเป็นแหล่งเดียวที่ระบุว่าคือซีรีส์ How Anthropic uses Claude
  • เวลาที่ประหยัด (30 นาทีเหลือไม่กี่นาที) เป็นการประเมินของผู้พูดเอง และตัวอย่าง Acme Corp เป็นบัญชีสมมติ
  • ไม่ได้แสดงเนื้อหาของไฟล์ skill จริงบนจอให้อ่านใน transcript
