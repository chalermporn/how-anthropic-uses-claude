How Anthropic uses Claude — สรุปภาษาไทยทั้งเพลย์ลิสต์

สรุปครบทุกคลิป (8 คลิป) จากเพลย์ลิสต์ How Anthropic uses Claude ของ Anthropic: พนักงานเล่างานจริงด้วย Claude Cowork และ Claude Code ใน GTM กฎหมาย มาร์เก็ตติ้ง ขาย security และ PM สรุปโดย AI จาก transcript อัตโนมัติ ตรวจกับวิดีโอก่อนอ้างอิง

  1. #01 จาก AE ไม่เคยเขียนโค้ด สู่คนสร้างตัวช่วยร่างอีเมลลูกค้าด้วย Claude

    Jared เล่าว่าตอนเป็น account executive ต้องดูแลลูกค้า 600-700 บัญชี ตอบอีเมลถึงสองสามทุ่มทุกวัน เลยสร้างเครื่องมือชื่อ Class (Claude Draft) ที่ใช้ Claude API ร่างอีเมลตอบลูกค้าให้ ผู้พูดบอกว่าประหยัดเวลาได้อย่างน้อย 2-3 ชั่วโมงต่อวัน และทำให้ย้ายสายงานมาเป็น go-to-market architect ได้

  2. #02 ทนายความ in-house ใช้ Cowork ไล่ตามบริบทเก่าให้ทันในไม่กี่นาที

    Mark ทนายความฝั่งผลิตภัณฑ์ของ Anthropic ตั้ง Claude Cowork ให้รันงานตอนเช้า แล้วใช้ skill /brief ดึง review เก่า กับ thread ใหม่ใน Slack และ Gmail มาสรุปเป็น brief สั้นๆ ที่ชี้ว่าอะไรเปลี่ยน ทุกข้อเช็กกลับไปที่ต้นฉบับได้ก่อนส่งคำตอบ โดยยังมีคนอนุมัติทุกขั้น

  3. #03 ทำ weekly metrics review ด้วย Cowork: Claude เตรียมตัวเลข คนเป็นคนกำหนดเรื่องเล่า

    Ian ทำ metrics review รายสัปดาห์ (เอกสารเต็มสำหรับทีมมาร์เก็ตติ้ง กับสไลด์เดียวสำหรับผู้บริหาร) โดยแปลงขั้นตอนเป็น skill ใน Cowork ให้ Claude ดึงและตรวจตัวเลข ส่วนคนตัดสินว่าจะเล่าเรื่องอะไร เพราะขั้นตอนอยู่ใน skill จึงรันซ้ำได้เหมือนเดิมทุกสัปดาห์และแชร์ให้ทีมได้

  4. #04 AE ใช้ Cowork เตรียมประชุมลูกค้าครั้งแรกและสรุปงานหลังประชุมในไม่กี่นาที

    Brittany สร้าง skill ใน Cowork ชื่อ account strategy builder ที่ดึงข้อมูลลูกค้าจาก Salesforce, data warehouse, อีเมล, Slack และเว็บพร้อมกัน แล้วสรุปเป็น account brief ก่อนประชุมครั้งแรก หลังประชุมใช้ skill call transcript processor สร้าง action items, ข้อความ Slack ภายใน และข้อความตามลูกค้า ทั้งหมดรออนุมัติก่อนส่ง

  5. #05 ทีม security ใช้ Claude Code สร้าง CLUE ให้ triage alert เหลือเป็นนาที

    ทีม detection ของ Anthropic สร้าง CLUE แพลตฟอร์ม detection and response ด้วย Claude Code ที่ต่อกับ data warehouse, Slack และ code base ภายใน ให้ Claude วางแผนสืบสวน alert แล้วยิง query เอง ผู้พูดบอกว่างานที่เคยใช้หลายชั่วโมงถึงหลายวันเหลือเป็นนาที และ Claude Code ช่วยให้คนใหม่ทำ suppression engine เสร็จในสัปดาห์เดียว

  6. #06 วิศวกร backend ใช้ Claude Code + Playwright MCP ทำ Excel renderer บนฝั่ง frontend

    Chuma Kabaghe เป็น backend engineer ที่ใช้ Claude Code ทำความเข้าใจ codebase frontend ที่ไม่คุ้น แล้วต่อ Playwright MCP ให้ Claude เปิดแอปดูผล แก้ และวนทดสอบเอง เดโมทำฟีเจอร์ preview ไฟล์ Excel, CSV, TSV ใน Claude.ai เธอบอกว่าเวลาที่เหลือเอาไปคิดระดับระบบและ trade-off มากขึ้น

  7. #07 PM ใช้ Claude Code ดึงข้อมูลผ่าน BigQuery MCP และขยาย test case ของ evals โดยไม่ต้องเขียน SQL

    Lisa Crofoot เล่าว่า PM ที่ Anthropic ใช้ Claude Code ต่อกับ BigQuery MCP ที่ทีม data science ตั้งไว้ เพื่อถามข้อมูลผลิตภัณฑ์และทำกราฟได้เองโดยไม่ต้องเขียน SQL อีกด้านคือให้ Claude ขยาย test case สำหรับ evals จากตัวอย่างไม่กี่อันเป็นราว 50 อัน เป้าหมายคือให้ PM มีเวลากับกลยุทธ์ การคุยลูกค้า และการตัดสินใจมากขึ้น

  8. #08 นักการตลาดที่ไม่เคยเขียนโค้ด ใช้ Claude Code สร้าง Figma plugin สร้างโฆษณาหลายแบบใน 30 วินาที

    Austin Lau ไม่เคยเขียนโค้ดมาก่อน ใช้ Claude Code สร้าง Figma plugin ที่รับ headline หลายแบบครั้งเดียว แล้วสร้างโฆษณาแต่ละแบบเป็น frame แยก ผู้พูดบอกว่างานที่เคยใช้ราว 30 นาทีเหลือราว 30 วินาที และแนะนำให้เริ่มจากงานซ้ำๆ เล็กๆ ที่อธิบายปัญหาให้ชัดได้
